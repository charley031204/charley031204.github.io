# 종선이를 잡아라!

얼굴이 빼꼼 올라오면 뿅! 60초 동안 종선이를 잡는 HTML5 미니게임입니다.

## 실행

ZIP을 받았다면 먼저 **압축을 모두 풀고 `index.html`을 더블클릭**하세요. 사진과 소리가 들어 있는 완성본이라 설치나 인터넷 연결이 필요 없습니다. 소리는 **게임 시작**을 눌렀을 때 켜집니다.

개발용 미리보기는 Node.js가 있을 때 `npm start`를 실행하고 `http://127.0.0.1:4173`을 엽니다. 이 주소는 실행 중인 컴퓨터에서만 열립니다.

## 조작과 규칙

| 조작 | 기능 |
| --- | --- |
| 얼굴 클릭 또는 터치 | 망치로 잡기 |
| 숫자키 1–7 | 같은 번호 구멍 때리기 |
| P 또는 Esc | 일시정지 / 이어서 하기 |
| 오른쪽 위 소리 설정 | 효과음·음악 별도 켜기/끄기, 음량 조절 |

- **일반 종선이:** 10점. **황금 종선이:** 30점.
- 연속 1–5타는 1배, 6–10타는 2배, 11–15타는 3배, 16타부터 4배입니다.
- 얼굴을 놓치거나 빈 구멍을 때리면 콤보가 끊깁니다.
- 폭탄을 때리면 점수가 최대 30점 줄고 하트가 하나 사라집니다. 점수는 0 아래로 내려가지 않습니다.
- 60초가 지나거나 폭탄을 세 번 때리면 끝납니다. 살살·보통·매운맛은 등장 속도가 다릅니다.
- 탭을 옮기면 자동으로 일시정지합니다. 돌아온 뒤 **이어서 하기**를 누르세요.
- 최고 기록은 난이도별로 현재 브라우저에 저장됩니다. 비공개 모드 등에서 저장이 제한돼도 게임은 실행됩니다.
- 결과 적중률은 `잡은 얼굴 ÷ (잡은 얼굴 + 놓친 얼굴 + 헛스윙 + 때린 폭탄)`입니다.

## 얼굴과 소리

제공된 얼굴 사진 두 장을 참조해 내장 `image_gen`으로 제작했습니다. 맞았을 때는 눈을 꽉 감고 입을 크게 벌린 표정과 머리 위의 **“빵!”** 만화 폭발 이미지가 함께 나타납니다. 망치 애니메이션과 별 파티클도 겹쳐집니다.

- `assets/faces.png`: 정상/타격 표정 2칸 sprite atlas. 녹색 배경은 게임 화면에서 chroma-key 필터로 제거합니다. 이미지 파일 자체는 RGB입니다.
- `assets/prompts.md`: 생성 및 수정에 사용한 프롬프트 전체.
- `audio.js`: 고무망치 타격, 콤보, 황금, 헛스윙, 폭탄, 등장, 카운트다운, 결과 효과음과 배경 음악. 외부 음원 파일 없이 Web Audio로 합성합니다.

원본 사진 파일은 수정하지 않았습니다. 서버 업로드나 계정 기능은 없습니다.

## 검증 및 수정

게임 규칙과 오디오 상태 테스트는 `npm test`로 실행합니다. 브라우저 검사는 Edge가 설치된 환경에서 `npm install`로 개발 도구를 준비한 뒤 다음 명령을 사용합니다. 게임만 즐길 때는 이 설치 과정이 필요 없습니다.

```text
npm start
node tests/browser.cjs
node tests/full-game.cjs
node tests/lifecycle.cjs
```

검증 결과와 한계는 `docs/verification.md`에 기록합니다. 게임 시간·점수 규칙은 `engine.js`, 화면은 `styles.css`, 입력과 기록 저장은 `game.js`에서 수정할 수 있습니다.
