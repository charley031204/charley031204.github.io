# 종선 잡기 게임 설계

사용자는 얼굴 사진 두 장과 게임 예시를 제공했으며 계획·서브에이전트·이미지·타격음 구현을 위임했다. HTML5 오프라인 게임으로 구현하며 계정, 서버 저장, 배포는 필요하지 않다.

## 화면과 자산
- 밝은 하늘과 연둣빛 들판, 흙 구멍 7개(윗줄 3개, 아랫줄 4개). 데스크톱은 1120px 게임판, 모바일은 화면 너비에 맞춘다.
- 게임판 위에 점수, 남은 시간, 하트 세 개, 최고 기록. 바깥은 차분한 아이보리와 짙은 초록, 게임판은 장난감 같은 테두리와 햇빛 색상.
- 색상: ink #23382d, sky #b7e7ec, grass #9ec46d, moss #4e753e, butter #f5ce67, coral #e86b4c. 한글은 Malgun Gothic 계열 두꺼운 제목, 본문은 시스템 산세리프, 숫자는 monospace.
- 제공된 얼굴 특징과 안경을 보존한 정상/찡그린 표정을 image_gen으로 제작한다. 사용자 추가 요청에 따라 눈을 꽉 감고 입을 크게 벌린 고통스러운 표정과 머리 위의 '빵!' 폭발을 직접 이미지에 포함한다. 생성기는 RGB를 반환했으므로 녹색 배경 자산을 SVG chroma-key 필터로 게임 안에서 합성한다.

## 규칙
- 기본 60초. 난이도 easy/normal/hard. 하트 3개는 폭탄을 때릴 때만 감소한다.
- 일반 얼굴 +10, 황금 얼굴 +30, 연속 5타마다 배수 증가(최대 4배). 얼굴을 놓치거나 빈 구멍을 치면 콤보 초기화. 폭탄은 점수 30 차감(0 하한), 하트 1 감소, 콤보 초기화.
- 끝나면 점수, 최고 콤보, 적중률, 최고 기록, 재시작. 난이도별 최고 기록은 localStorage에 저장하며 접근 실패에도 게임은 계속된다.
- 클릭/터치와 1~7 키, P/Escape 일시정지. 탭을 숨기면 자동 일시정지. 일시정지 시 모든 게임 시간이 정지한다.
- 타격 중복 점수 금지. 시간 종료 후 입력 무효. 새 게임은 이전 상태를 모두 초기화한다.

## 구성
- index.html, styles.css, game.js: 화면, 입력, 애니메이션, 저장.
- engine.js: DOM 없이 결정적으로 테스트 가능한 게임 상태와 규칙. 브라우저 global GameEngine과 CommonJS 지원.
- audio.js: Web Audio 합성 타격/헛스윙/폭탄/등장/카운트다운/결과음, 가벼운 루프 음악. 사용자 시작 동작 후 활성화. 효과음/음악 별도 토글, 전체 볼륨 조절.
- assets/: 생성 얼굴 PNG, 간단한 게임 SVG. scripts/server.cjs: 127.0.0.1 전용 미리보기.
- tests/: Node 게임 규칙 검사, Playwright 데스크톱/모바일/키보드/종료/오디오 검사.

## 완료 기준
원본 얼굴을 알아볼 수 있는 생성 찡그림이 실제 타격 시 보인다. 모든 규칙, 음소거, 일시정지, 재시작이 검증된다. 브라우저 콘솔 에러가 없고 모바일에서 가로 넘침 없이 조작된다. index.html 더블클릭으로 실행 가능하며 ZIP과 한국어 설명을 제공한다.
